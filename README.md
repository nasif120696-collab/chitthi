# চিঠি (CHITTHI) — Multi-Page Vintage Postal Web Application

## ফাইল স্ট্রাকচার (Project Structure)
- `index.html` — ৫-সিনের ভিন্টেজ লেটারবক্স ইন্ট্রো অ্যানিমেশন + মেইন ড্যাশবোর্ড
- `write.html` — রাইটিং ডেস্ক (কলম ও হাতের অ্যানিমেশন, কাগজ, ওয়াক্স সিল, টাইম-লক ও বার্ন-আফটার-রিডিং)
- `open.html` — প্রাপকের চিঠি খোলার পেজ (মোমের সিল ভাঙা, হাতের লেখার রিপ্লে, গোপন উত্তর ও স্টোরি কার্ড)
- `postbox.html` — পার্সোনাল পোস্টবক্স তৈরি ও `#BD-XXXX` গোপন কোড ট্র্যাকার
- `js/firebase-config.js` — এখানে আপনার Firebase Config বসালেই পুরো সাইট লাইভ ডাটাবেসে যুক্ত হয়ে যাবে।
